# Prompt para diseño de interfaces minimalistas con estilo mecha

Necesito diseñar una interfaz minimalista con estética mecha para mi proyecto. Busco un enfoque abstracto que combine funcionalidad y estética futurista inspirada en diseños mecánicos y robóticos.
Con tematica de evangelion

importante: solo debes modificar el componente y hacer que se acople al background que ya esta creado, no debes modificar el background.

## Paleta de colores Eva-01

La paleta de colores está inspirada en la unidad Eva-01 de Evangelion, combinando tonos oscuros con acentos neón vibrantes:

| Color | Código | Uso |
|-------|--------|-----|
| Púrpura Eva | `#4B3F72` / `#221c3a` (dark) | Color principal, representa el cuerpo de Eva-01 |
| Verde Eva | `#39FF14` | Acento principal, similar a los detalles luminosos de Eva-01 |
| Amarillo Eva | `#FFD600` | Acento secundario, para elementos de alerta o destacados |
| Acento Azul | `#8BE9FD` | Acento terciario, para enlaces y elementos interactivos |

### Sistema de temas claro/oscuro

El diseño implementa un sistema de temas con variables CSS personalizadas que cambian según el modo:

- **Modo claro**: Fondo blanco (`#ffffff`) con texto oscuro (`#111111`)
- **Modo oscuro**: Fondo oscuro (`#181825`) con texto claro (`#f8f8f8`)

### Aplicación en componentes

Los componentes utilizan esta paleta para crear una experiencia visual coherente:

- Contenedores con bordes sutiles y fondos secundarios
- Tipografía clara con pesos adecuados para jerarquía visual
- Enlaces con color distintivo y efecto hover para mejorar la interactividad
- Transiciones suaves entre estados para una experiencia fluida


## Tecnologías a utilizar
- **Framework**: SvelteKit
- **Estilos**: Tailwind CSS v4 + CSS personalizado
- **Gráficos 3D**: Three.js
