# Prompts para miWeb

Esta carpeta contiene prompts estructurados para mejorar las interacciones con asistentes IA como GitHub Copilot, ChatGPT u otros.

Cada prompt está diseñado para proporcionar contexto específico y generar respuestas más precisas para diferentes aspectos del proyecto.

## Estructura de carpetas

- `/svelte` - Prompts relacionados con componentes y lógica de SvelteKit
- `/tailwind` - Prompts para estilización y diseño con Tailwind CSS
- `/general` - Prompts de propósito general para desarrollo web
- `/configuracion` - Prompts para configuración del proyecto
- `/bugs` - Plantillas para reportar y solucionar problemas

## Cómo usar

Copia y pega el contenido del prompt relevante al inicio de tu consulta, completando las secciones entre `[corchetes]` con información específica de tu caso.
